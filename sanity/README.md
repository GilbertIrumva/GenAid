# Sanity starter for Generation Aid

This folder contains the first step of the Sanity migration for the Generation Aid website.

## Current status

- Sanity Studio schemas for posts, stories, programs, partners, and site settings are scaffolded.
- A seed script for posts is included.

## Next steps

1. Create a Sanity project and set SANITY_STUDIO_PROJECT_ID and SANITY_STUDIO_DATASET.
2. Add a SANITY_API_TOKEN with write access.
3. Run the seed script to publish sample posts.
4. Connect the website to this content source without changing the React UI shape.
